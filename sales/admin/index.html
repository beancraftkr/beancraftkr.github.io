🔑 로그인

처음 한 번만 GitHub 접근 토큰을 입력하면 이 브라우저에 저장됩니다. 다음부턴 바로 들어와집니다.
토큰 발급 방법 (관리자에게 받았으면 그대로 붙여넣기)
1. GitHub 토큰 발급 페이지 접속
2. Repository access → beancraftkr/beancraftkr.github.io 만 선택
3. Permissions → Contents → Read and write 체크
4. 생성된 github_pat_... 문자열을 위에 붙여넣기
