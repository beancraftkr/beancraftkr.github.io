# beancraft-guides

빈크래프트 카페 컨설팅 마케팅·영업 자료 호스팅 저장소.

> ⚠️ 이 저장소는 BeanCraft 영업관리 React 앱과 **완전히 분리**된 정적 자료 호스팅 전용입니다. 앱 코드와 절대 섞지 마세요.

## 폴더 구조

```
beancraft-guides/
├── marketing/         담당: 조희재 (0507-1488-9050)
│   └── late/          직원 지각 가이드
└── sales/             담당: 박찬호 (영업팀 정보 추후 등록)
```

## 배포 URL

- 직원 지각 가이드: https://beancraftkr.github.io/marketing/late/

## 자료 추가

```bash
./add-guide.sh marketing interior /path/to/source.html
./add-guide.sh sales 신규고객발굴 /path/to/source.html
```
